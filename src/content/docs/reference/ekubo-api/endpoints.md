The interactive reference is refreshed during every documentation build from the API's live OpenAPI 3.1 document.

- [Browse, search, and test requests in the API reference](/api/)
- [Download the build's OpenAPI snapshot](/openapi/ekubo.json)
- [View the canonical live specification](https://prod-api.ekubo.org/openapi.json)

The reference includes request parameters, response schemas, examples, generated client snippets, and an in-browser request tester. Use its API selector to switch between the Ekubo and Quoter APIs without leaving the page.
