# Introduction

[Starknet](https://starknet.io) is a layer-2 on Ethereum focused on scalability via ZK-proofs called STARKs, built by [Starkware](https://starkware.co/). The user experience of Starknet is similar to Ethereum, but the underlying virtual machine is the Cairo VM, based on the concept of "provable" programs. As a result, primitives such as AMMs on Ethereum need to be re-architected to work well on Starknet.

Ekubo is a next-generation AMM focused on taking full advantage of the Starknet architecture to create maximally efficient markets with extremely low fees. The key features are its singleton design, extensions, and concentrated liquidity that is unmatched in any other AMM. Use the flexibility of Ekubo to market making on Starknet in any style from completely passive liquidity to order-book style market making.
