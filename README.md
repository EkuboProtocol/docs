# Introduction

Starknet is a layer-2 on Ethereum focused on scalability via a class of ZK-proofs called STARKs. The user experience of Starknet is similar to Ethereum, but the underlying virtual machine is different, as it is based on the concept of "provable" programs. As a result, primitives such as AMMs on Ethereum need to be re-architected to work well on Starknet.

Ekubo is a next generation AMM focused on taking full advantage of the Starknet architecture to create maximally efficient markets for minimal cost. The key features are its singleton design, extensibility via extensions, and concentrated liquidity that is unmatched in any other AMM.
