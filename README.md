# Introduction

Ekubo is a next-generation AMM focused on taking full advantage of the Starknet architecture to create maximally efficient markets with extremely low fees. The key features are its singleton design, extensions, and concentrated liquidity that is unmatched in any other AMM. Use the flexibility of Ekubo to implement market making on Starknet in any style, from completely passive liquidity to order-book style market making.
