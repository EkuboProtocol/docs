# Swap

Ekubo does not provide its own swapping interface. You can swap using [AVNU](https://avnu.fi) or [Fibrous](https://fibrous.finance) and Ekubo protocol will be used when it provides the best execution. We believe users deserve the best price, which means aggregating all the liquidity in Ekubo as well as liquidity on other AMMs.

If you still wish to swap exclusively on Ekubo, you can do so using one of of the below links.
